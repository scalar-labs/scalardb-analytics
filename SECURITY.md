# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues, discussions, or pull requests.

Report them privately through GitHub's private vulnerability reporting instead:

1. Open the [Security tab](https://github.com/scalar-labs/scalardb-analytics/security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

The report is visible only to you and the maintainers.
See [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) in the GitHub documentation for details.

## What to include

A report is easier to act on when it includes:

- the affected component, such as the catalog server, the CLI, the client SDK, or the Spark connector;
- the affected ScalarDB Analytics version;
- the steps or a proof of concept to reproduce the issue; and
- the impact you expect an attacker to achieve.
